# Exemplo de output - Modo simplified

"Estudei IA e quero comecar um projeto sem me perder"

## Destaques esperados

- Linguagem simples
- Passos curtos de execucao
- Menor atrito para publicar no GitHub

## Trecho de exemplo

```md
## Foco

## Passos simples para comecar
1. Escolher um input curto e objetivo
2. Rodar generate para produzir os documentos principais
3. Ajustar os arquivos gerados e publicar no GitHub
```
